2. What is a REST API?

A REST API is simply a way for two applications to communicate over HTTP.

Example:

User types:

"What is Ayushman Bharat?"

The frontend sends a request to your backend.

POST /chat

Body:

{
  "message":"What is Ayushman Bharat?"
}

Backend processes it.

Backend returns

{
  "reply":"Ayushman Bharat is a Government healthcare scheme..."
}

That's a REST API.

3. What is fetch()?

fetch() is a built-in JavaScript function for calling APIs.

Example:

const response = await fetch("/api/chat",{
    method:"POST",
    headers:{
        "Content-Type":"application/json"
    },
    body:JSON.stringify({
        message:userMessage
    })
});

const data=await response.json();

console.log(data.reply);

Advantages

Built into JavaScript
No installation
Lightweight
4. What is Axios?

Axios is another way to call APIs.

Install

npm install axios

Example

import axios from "axios";

const response=await axios.post("/api/chat",{
    message:userMessage
});

console.log(response.data.reply);

Advantages

Simpler syntax
Better error handling
Automatic JSON parsing
Popular in React projects
Which one should you use?

For your project:

Axios is generally easier to work with in React applications.

6. What is docker-compose.yml?

Your project has multiple parts.

Frontend

Backend

Database

Instead of starting each manually,

docker-compose starts all of them together.

Example

version: "3.9"

services:

  frontend:
    build: ./frontend
    ports:
      - "3000:3000"

  backend:
    build: ./backend
    ports:
      - "8000:8000"

  database:
    image: postgres:16
    environment:
      POSTGRES_USER: admin
      POSTGRES_PASSWORD: password
      POSTGRES_DB: healthcare
    ports:
      - "5432:5432"

Run

docker compose up

Everything starts automatically.

Step-by-Step Deployment
Step 1: Develop your application
Frontend (React/Next.js)
Backend (FastAPI)
Database (PostgreSQL, if needed)
Step 2: Create a Dockerfile

Example for a FastAPI backend:

FROM python:3.12-slim

WORKDIR /app

COPY requirements.txt .

RUN pip install -r requirements.txt

COPY . .

CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]

Step 3: Build the Docker image
docker build -t healthcare-assistant .
Step 4: Run the container
docker run -d \
-p 8000:8000 \
--name healthcare-assistant \
healthcare-assistant

Your application is now running inside Docker.

Step 5: Deploy to a server

Copy your project to a Linux server (AWS EC2, Azure VM, DigitalOcean, etc.), install Docker, then run:

docker build -t healthcare-assistant .
docker run -d -p 8000:8000 healthcare-assistant

Users can access it at:

http://<server-ip>:8000

or, after configuring a domain:

https://healthcareassistant.com

✅ Modular (each component has a separate responsibility)

✅ Portable (runs the same on any Docker-enabled server)
✅ Suitable for DevOps projects
✅ Uses modern AI + Full-Stack + Docker technologies

This architecture is appropriate for a final-year AI + DevOps project and is much more realistic than deploying everything as a single application.

Project Title
AI-Driven Multilingual Healthcare Assistant for Rural Communities
Project Description

The AI-Driven Multilingual Healthcare Assistant for Rural Communities is a web-based intelligent virtual assistant designed to improve healthcare awareness and accessibility in rural areas. The application enables users to interact in their preferred language and provides reliable information about government healthcare schemes, eligibility criteria, required documents, nearby healthcare facilities, and frequently asked healthcare questions. By leveraging Artificial Intelligence (AI), Natural Language Processing (NLP), and Large Language Models (LLMs), the assistant delivers accurate, conversational, and easy-to-understand responses, helping bridge the gap between rural citizens and public healthcare services.

Abstract

Many rural communities face challenges in accessing reliable healthcare information due to language barriers, limited awareness of government healthcare schemes, and low digital literacy. This project proposes an AI-Driven Multilingual Healthcare Assistant that provides users with accurate healthcare information through natural language conversations in multiple regional languages. The system utilises Large Language Models (LLMs) and Natural Language Processing (NLP) to understand user queries and generate context-aware responses related to government healthcare schemes, eligibility, required documents, nearby healthcare facilities, and basic healthcare guidance. The application is developed using a modern full-stack architecture and deployed using Docker-based containerisation. The proposed solution aims to improve healthcare awareness, enhance digital accessibility, and provide a scalable virtual assistant for rural communities.

Problem Statement

Rural citizens often struggle to obtain accurate and timely information about government healthcare schemes due to language differences, limited internet literacy, and complex government portals. Existing systems provide fragmented information and lack multilingual conversational support. An intelligent multilingual assistant can simplify access to healthcare information and improve public awareness.
